# STEP Semester 3 — Week 5 Assignment

**Topic:** Java Arrays and Methods — Category C

## Problems Solved

1. **Fantasy Team Score Multiplier** — Modifying array elements using method parameters.
2. **Duplicate Player Pick Checker** — Finding duplicate strings using nested loops.
3. **Top Performer Tracker** — Finding minimum, maximum, and spread in a single pass.
4. **Match Day Grid Analyzer** — Using 2D arrays and a reusable row-average method.
5. **Fantasy League Auto-Draft Ranking Engine** — Method overloading, constructors, encapsulation, `Comparable`, and `Arrays.sort()`.

## Technologies Used

- Java
- Arrays and 2D arrays
- Methods and method overloading
- Constructors and encapsulation
- `Comparable` and `Arrays.sort()`

## How to Run

Compile and run a problem from the project root using:

```powershell
javac Week-05\Problem1.java
java -cp Week-05 Problem1
```

Replace `Problem1` with `Problem2`, `Problem3`, `Problem4`, or `Problem5` to run another problem.
