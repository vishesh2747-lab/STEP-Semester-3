# STEP Semester 3 — Week 5 Practice

**Topic:** Java Arrays and Methods — Category C

## Problems Solved

1. **Hackathon Score Curve Booster** — Modifying array elements and using `Arrays.toString()`.
2. **Duplicate Team Name Finder** — Detecting duplicate strings using nested loops.
3. **Top-3 Podium Finder** — Finding the three highest scores in a single pass without sorting.
4. **Hackathon Seating Grid Optimizer** — Using 2D arrays and a reusable row-average method.
5. **Placement Drive Shortlisting & Ranking Engine** — Method overloading, constructors, `Comparable`, and `Arrays.sort()`.

## Technologies Used

- Java
- Arrays and 2D arrays
- Methods and method overloading
- Constructors and encapsulation
- `Comparable` and `Arrays.sort()`

## How to Run

From the project root, compile and run a practice problem using:

```powershell
javac Week-05\Practice\Practice1.java
java -cp Week-05\Practice Practice1
```

Replace `Practice1` with `Practice2`, `Practice3`, `Practice4`, or `Practice5` to run another problem.
