# STEP Semester 3 — Week 7 Assignment

**Topic:** Encapsulation and Access Control — Category C

## Problems Solved

1. **The Health Bar** — Encapsulation, private health, fixed maximum health, damage, and healing.
2. **The Playlist** — Private arrays, defensive copying, and read-only song count.
3. **The Password Checker** — Private immutable password and strength rating.
4. **The Traffic Light** — Controlled state changes, read-only color, and final ID.
5. **The Shopping Cart** — Private price array, item count, total calculation, and final cart ID.

## Technologies and Concepts

- Java
- Classes and objects
- Encapsulation using `private`
- Immutable fields using `final`
- Defensive copying of arrays
- Read-only access through getter methods
- State changes through controlled methods
- Arrays and loops

## How to Run

Open the terminal in the `Week-07` folder.

Compile and run a problem using:

```powershell
javac Problem1.java
java Problem1
```

Replace `Problem1` with `Problem2`, `Problem3`, `Problem4`, or `Problem5` to run another assignment problem.
