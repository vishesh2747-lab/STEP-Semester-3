# STEP Semester 3 — Week 7 Practice

**Topic:** Encapsulation and Access Control — Category C

## Problems Solved

1. **The Piggy Bank** — Encapsulation, private savings, deposits, withdrawals, and a final ID.
2. **The Quiz Scorecard** — Private answer array, fixed question count, and score calculation.
3. **The Nickname Tag** — Immutable name fields, constructor-based string splitting, and nickname generation.
4. **The Locker Code** — Private combination code, controlled code changes, and a final locker number.
5. **The Attendance Sheet** — Private names array, duplicate prevention, attendance count, and presence lookup.

## Technologies and Concepts

- Java
- Classes and objects
- Encapsulation using `private`
- Immutable fields using `final`
- Constructor-based initialization
- Arrays and loops
- Controlled modification of private fields
- Read-only information through methods

## How to Run

Open the terminal in the `Week-07` folder.

Compile and run a practice problem using:

```powershell
javac Practice\Practice1.java
java -cp Practice Practice1
```

Replace `Practice1` with `Practice2`, `Practice3`, `Practice4`, or `Practice5` to run another practice problem.
