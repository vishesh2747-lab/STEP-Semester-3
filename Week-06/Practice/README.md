# STEP Semester 3 — Week 6 Practice

**Topic:** Classes and Objects — Category C

## Problems Solved

1. **Student Placement Record Management** — Classes, constructors, arrays of objects, and instance methods.
2. **Hostel Mess Wallet Management** — Encapsulation, private balance, top-ups, and deductions.
3. **Course Credit Management** — Constructor overloading, constructor chaining using `this()`, and total credits.
4. **Library ID Card Management** — Object references and comparison using `==`.
5. **Student and College Information Management** — Static fields, static methods, and shared student count.

## Technologies and Concepts

- Java
- Classes and objects
- Constructors and constructor overloading
- Encapsulation using `private`
- Constructor chaining using `this()`
- Object references
- Static variables and methods
- Arrays of objects

```powershell
javac Week-06\Practice\Practice1.java
java -cp Week-06\Practice Practice1
```

Replace `Practice1` with `Practice2`, `Practice3`, `Practice4`, or `Practice5` to run another problem.
