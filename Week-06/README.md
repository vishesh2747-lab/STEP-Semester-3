# STEP Semester 3 — Week 6 Assignment

**Topic:** Classes and Objects — Category C

## Problems Solved

1. **Library Inventory Management** — Classes, constructors, arrays of objects, and instance methods.
2. **Payroll Salary Management** — Encapsulation, private fields, bonus crediting, and tax deduction.
3. **Employee Profile Creation** — Constructor overloading and constructor chaining using `this()`.
4. **Exam Hall Ticket Reference Management** — Object references and comparison using `==`.
5. **Employee and Company Information Management** — Static fields, static methods, and shared employee count.

## Technologies and Concepts

- Java
- Classes and objects
- Constructors and constructor overloading
- Encapsulation using `private`
- Constructor chaining using `this()`
- Object references
- Static variables and methods
- Arrays of objects

## How to Run

From the project root, compile and run a problem using:

```powershell
javac Week-06\Problem1.java
java -cp Week-06 Problem1
```

Replace `Problem1` with `Problem2`, `Problem3`, `Problem4`, or `Problem5` to run another problem.
