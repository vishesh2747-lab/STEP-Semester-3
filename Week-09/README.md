# STEP Semester 3 — Week 09 Assignment

This folder contains the five Java programming problems from the Week-09 assignment.

## Problems

| File | Problem Name | Concepts Used |
|---|---|---|
| Problem1.java | Movie Ticket Counter | Abstraction, Inheritance, Common Convenience Fee |
| Problem2.java | Parcel Shipping Desk | Abstract Classes, Method Overriding, Insurance Calculation |
| Problem3.java | College Fee Counter | Abstraction, Inheritance, Fee Calculation |
| Problem4.java | City Cab Fare Meter | Abstraction, Inheritance, Method Overriding, Night Fare |
| Problem5.java | Home Appliance Energy Report | Abstraction, Inheritance, Energy Consumption, Saver Mode |

## Problem Descriptions

### Problem 1: Movie Ticket Counter
Calculates ticket prices for REGULAR, PREMIUM, and RECLINER seats. A common convenience fee of 20 per ticket is applied to all seat types.

### Problem 2: Parcel Shipping Desk
Calculates shipping charges and insurance for STANDARD, EXPRESS, and FRAGILE parcels based on weight and declared value.

### Problem 3: College Fee Counter
Calculates fees for DAY_SCHOLAR, HOSTELLER, and SCHOLAR students, including tuition and applicable transport or hostel charges.

### Problem 4: City Cab Fare Meter
Calculates fares for MINI, SEDAN, and SUV cabs based on distance, minimum fare, and applicable night charges. MINI cabs do not support night service.

### Problem 5: Home Appliance Energy Report
Calculates electricity consumption and cost for FRIDGE, AC, TV, and WASHER appliances. Saver mode reduces energy consumption by 25% where supported.

## How to Compile and Run

Open the terminal in this folder and compile each program separately:

```bash
javac Problem1.java
java Problem1
```

Replace `Problem1` with `Problem2`, `Problem3`, `Problem4`, or `Problem5` to run another program.

## Concepts Practiced

- Abstract classes and methods
- Inheritance and method overriding
- Runtime polymorphism
- Common functionality in base classes
- Conditional logic and calculations
- Input handling using `Scanner`
- Formatted output using `System.out.printf()`
