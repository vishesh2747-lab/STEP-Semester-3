
# Week-08 Practice Problems

This folder contains Java practice problems for Week 08, focusing on inheritance and polymorphism.

## Problems

1. Payment System Fee Calculation
2. Library Item Due Date Calculator
3. Delivery Fee Calculator
4. Examination Question Grader
5. Public Transport Fare Calculator

## Concepts Covered

- Inheritance
- Abstract classes and methods
- Method overriding
- Runtime polymorphism
- Polymorphic arrays
- Date calculations using `LocalDate`
- Input and output using `Scanner`

## Language

Java
